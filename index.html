Good to know
The honest details.

    

      
Is it actually any good — or a gimmick?
        
It's built to a real standard: evidence-based programming, progressive overload, proper warm-ups, deloads, and hard safety rails (it won't hand you "1000 push-ups", won't program through injury, and refuses crash diets). The goal is a program a qualified trainer would look at and call sound. It won't replace a great coach who watches your form in person — but for planning, logging, and progressing, it's genuinely capable.

      
Which AI tools does it work with?
        
Claude Code (command line, desktop, mobile app) and OpenAI Codex (CLI, plus cloud/mobile in the ChatGPT app). Both run git and read/write files — that's what makes auto-save and phone sync work. Plain ChatGPT without Codex won't fully work. Use a capable, recent model for best results.

      
Do I need a paid subscription?
        
Yes — but a usage-limited tier is plenty for ~3 sessions a week: Claude Pro/Max for Claude Code, or ChatGPT Plus/Pro for Codex (or pay-as-you-go API credits). GitHub is free. So there's no personal-trainer bill — just the AI you likely already pay for.

      
Why GitHub — and can I really use my phone?
        
GitHub is free cloud storage that syncs your training data between laptop and phone and backs it up. That's what lets you start a session at the gym from your phone and pick it up later on your computer. The prompt walks you through a free account if you don't have one.

      
What languages does it speak?
        
All of them — it runs the interview, your sessions, and your files in whatever language you write in.

      
Is my data private?
        
Yes. The repo is created private and holds your personal health data — nothing is shared or published. The project is open source, so you can read exactly what the prompt does.
